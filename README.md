# FreshFold Laundry – Website

A responsive, animated, accessible one-page website for a laundry & dry-cleaning business.

## Folder structure
```
freshfold-laundry/
├── index.html        Main page (all sections and content)
├── css/style.css     Colours, layout, animations, mobile styles
├── js/main.js        Mobile menu, booking form, service picker, FAQ
└── images/           16 SVG illustrations (machine, drum, van, services, clothesline)
```

## How to open
Double-click `index.html` in your browser. Keep the folders together.

## Before going live
- Replace placeholders in `index.html`: `[YOUR PHONE]`, `[YOUR EMAIL]`, `[STORE ADDRESS, CITY, PIN]`, `[HOURS]`, `₹[PRICE]`, `₹[MIN ORDER]`, `[YOUR %]`, `[X]` stats.
- Replace `910000000000` (call/WhatsApp links) and `hello@example.com` with your real details.
- Paste real customer reviews into the review cards.
- The booking form currently shows a confirmation only. Connect it to Formspree, Google Forms, email or WhatsApp to receive bookings.

## Publish
Upload the whole folder to any host: Netlify (drag & drop), GitHub Pages, Hostinger, GoDaddy, etc.
